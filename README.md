# Stroll Flutter Application
Stroll is a Flutter-based mobile application designed to provide a seamless user experience by presenting interactive content with visually appealing UI components. This project features structured widget separation, responsive design, and a robust architecture using the MVVM (Model-View-ViewModel) pattern.

## Features
-Dynamic content loading and state management with Provider

-User-friendly interface with custom widgets for header, author information, and options selection

-Background images and themed UI for better user engagement

-Voice interaction components and navigation controls

-Error handling and loading indicators for a seamless experience

# Project Structure

```bash

lib/
|-- models/
|   |-- stroll_post_model.dart   # Model for post data
|
|-- viewmodels/
|   |-- stroll_view_model.dart   # ViewModel for data handling
|
|-- views
|   |--widgets/
|      |-- author_info.dart         # Widget for displaying author information
|      |-- header_widget.dart       # Widget for header content

|      |-- bottom_bar.dart          # Widget for bottom navigation
|
|-- |--screens/

## Getting Starte
- Clone the Repository:

```bash
 git clone https://github.com/ayklassiq/stroll.git
 cd stroll
 ```
     


## Install Dependencies:

```bash
    flutter pub get
```
## Run the App:
Connect your device or start an emulator.

Run the following command:

```bash
flutter run
```
